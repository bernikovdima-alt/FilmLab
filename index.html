FilmLab — плёнка

Конвертация негативов и коррекция фотографий

1. Фотография

Выберите фотографию.

Если встроенная камера недоступна, используйте «Снять фото» для открытия штатной камеры.

2. Настройки обработки

Изменения применяются сразу. Сброс отдельного ползунка не сбрасывает остальные настройки.

3. Маска плёнки

Выберите пипетку и укажите на исходном негативе участок прозрачной основы плёнки без изображения, если он доступен. Цвет используется для компенсации цветовой маски негатива.

Цвет маски не выбран.

4. Баланс белого позитива

Нажмите «Пипетка баланса белого», затем выберите на изображении «Результат» участок, который должен быть белым или нейтрально-серым. Цветовые каналы всей фотографии будут скорректированы относительно выбранной точки.

Баланс белого не задан.

Для лучшего результата выбирайте участок без пересвета и без выраженного цветового оттенка. Нейтрально-серая область тоже подходит.

Исходник
Результат — нажмите для выбора точки баланса белого

Фотографии обрабатываются локально в браузере. Пакетная обработка использует текущие настройки и выбранные коррекции цвета.
